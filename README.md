## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```text
/
├── index.html              ← หน้าเว็บหลัก (Optimized)
├── robots.txt              ← การตั้งค่าการจัดเก็บข้อมูลของ Search Engine
├── sitemap.xml             ← แผนผังเว็บไซต์สำหรับ SEO
├── .htaccess               ← การตั้งค่า Caching, Gzip และ HTTPS (Apache/cPanel)
├── favicon.ico             ← ไอคอนเบราว์เซอร์
├── apple-touch-icon.png    ← ไอคอนบนหน้าจอ iOS / Safari
└── assets/
    ├── img/                ← รูปภาพทั้งหมด (WebP Format)
    │   ├── hero-bg.webp
    │   ├── og-image.jpg    ← ภาพพรีวิวสำหรับ Social Media (LINE/Facebook)
    │   ├── portfolio-01..15.webp
    │   └── team-01..16.webp
    └── video/
        └── hero-video.mp4  ← วิดีโอพื้นหลัง (Compressed)
